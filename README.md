SideMid

Chat with devices connected to the same Wi-Fi network.

SideMid is a simple Android chat app that lets devices communicate with each other when they're connected to the same local Wi-Fi network.

Features

- 📱 Discover devices on the same Wi-Fi network
- 💬 Send messages between connected devices
- 🌐 Local network communication
- 🔒 Messages stay on the local network
- ⚡ No internet connection required for local chatting

How it works

SideMid looks for other devices running SideMid on the same Wi-Fi network and allows them to communicate directly over the local network.
